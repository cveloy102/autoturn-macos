# AUTO<span>TURN_</span> для macOS

**Дома — напрямую. Вне дома — VPN.** Нативное приложение AmneziaWG 3.1 для Intel и Apple Silicon. powered by **LENCHA_**.

[Скачать последнюю версию](https://github.com/cveloy102/autoturn-macos/releases/latest) · [Страница установки](https://cveloy102.github.io/autoturn-macos/) · [Проверки Intel / Apple Silicon](https://github.com/cveloy102/autoturn-macos/actions)

## Возможности

- Автоматически включает VPN вне заданных домашних Wi-Fi и отключает дома. Ручные «Включить» и «Выключить», возврат в «Авто».
- Весь интернет через AmneziaWG. Несколько профилей, проверка HTTPS через туннель, резерв по порядку при повторных отказах. При отказе всех профилей прямой доступ вне дома остаётся закрытым.
- Импорт `.conf` кнопкой и перетаскиванием, параметры AmneziaWG 3.1. Профили и настройки в Связке ключей macOS.
- Пульт и живое верхнее меню. По три оформления в настройках; темы пульта и шторки независимы. Закрытие пульта не останавливает приложение.
- Подписанные обновления с GitHub: проверка раз в час, уведомление один раз о каждой новой версии, ручная проверка. Установка сохраняет настройки и профили.

## Установка

macOS **13.0+**. Один ZIP для **x86_64 + arm64**; на Apple Silicon Rosetta приложению не нужна.

1. Скачать ZIP из Releases, распаковать, перенести `AutoTurn.app` в «Программы».
2. Открыть приложение. При необходимости разрешить запуск именно AutoTurn в «Системные настройки → Конфиденциальность и безопасность».
3. Импортировать AmneziaWG `.conf` и установить VPN-службу кнопкой в пульте. macOS запросит права администратора.
4. Разрешить определение имени Wi-Fi, задать домашние сети и выбрать «Авто».

Приложение имеет ad hoc подпись, без Developer ID/нотариализации. При обновлении macOS может повторно попросить доступ к профилям в Связке ключей: сами данные сохраняются.

## Обновления

Автоматическая проверка выполняется при работающем приложении, раз в час после успешной проверки. Запуск и пробуждение проверяют, наступил ли срок. Ошибки фоновой проверки не показывают уведомлений; повторная попытка — через час. Ручная кнопка проверяет независимо от расписания.

Уведомление приходит строго один раз на номер версии, без повторных напоминаний. Индикатор в пульте и шторке сохраняется после перезапуска и открывает установку. Загрузка и установка выполняются после выбора пользователя. Метаданные и архив подписаны Ed25519, дополнительно проверяются SHA-256, версия macOS, подпись приложения и наличие обеих архитектур у приложения, helper и движка. Данные в Keychain не заменяются установщиком.

## Проверки и границы

В CI используются нативные Intel и Apple Silicon раннеры. Общие и сервисные тесты, сборка, AppKit-проверка шторки, запуск движка/службы и проверка подписи клиента Unix IPC. Опубликованный ZIP дополнительно запускается на этих же архитектурах.

Реальные режимы, HTTPS и возврат между Wi-Fi проверены на Intel Mac. CI без пользовательского VPN-профиля проверяет выполнение arm64-кода и интеграцию компонентов; работу конкретного VPN-сервера и домашней сети на Mac получателя нужно проверить отдельно.

## Сборка и выпуск

```sh
bash scripts/test.sh
bash scripts/build.sh
bash scripts/smoke.sh
```

Нужны совместимые Command Line Tools/Xcode и Go 1.25.0. Полный Xcode-проект не требуется. Минимальный target — macOS 13.0.

Движок закреплён: [amneziawg-go v3.1.20260828](https://github.com/amnezia-vpn/amneziawg-go/tree/v3.1.20260828), commit `b5928efb6ca19f0153958460c3d141f04abc5c2e`. Его лицензия включена в `third_party/` и приложение. Отдельные каталог UAPI, Unix socket и PF-якорь AutoTurn.

Релиз подписывается локально:

```sh
python3 scripts/prepare-release.py --key /secure/location/autoturn-update.private --notes release-notes.md
```

Публикуются `AutoTurn-<version>-macOS.zip` и `macos-update.json` под тегом `macos-v<version>`. Приватный ключ выпуска не хранится в GitHub; сохраняй его резервную копию для следующих обновлений. Скрипт требует универсальную сборку с соответствующим публичным ключом.

[Android-проект](https://github.com/cveloy102/autoturn-vpn) имеет отдельные релизы и канал обновлений.
