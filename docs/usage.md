# AutoTurn: инструкция

[Скачать](https://github.com/cveloy102/autoturn-macos/releases/latest) · [Главная](../README.md) · [Изменения 1.0.4](../releases/1.0.4/notes.md)

## Первый запуск

1. Распакуйте ZIP и перенесите `AutoTurn.app` в `/Applications` («Программы»).
2. Откройте AutoTurn. При блокировке разрешите запуск конкретного приложения через «Системные настройки → Конфиденциальность и безопасность».
3. Импортируйте выданный вашим VPN-сервером профиль AmneziaWG `.conf` кнопкой или перетаскиванием. AutoTurn не создаёт VPN-сервер.
4. Мастер проверит VPN-службу и сам предложит системный запрос установки/обновления, если это необходимо. Подтвердите права администратора.
5. Для автоматического режима разрешите геолокацию AutoTurn и добавьте домашние Wi-Fi. Это разрешение нужно macOS для чтения имени сети; координаты не сохраняются и не отправляются.

## Режимы

| Режим | Поведение |
| --- | --- |
| Авто | Дома напрямую, вне дома подключение к VPN |
| Включить | VPN независимо от домашней сети |
| Выключить | Прямой интернет, VPN отключён |

При нескольких профилях AutoTurn проверяет доступность HTTPS через туннель и использует резерв по порядку после повторных отказов. Если все профили недоступны, трафик, предназначенный для VPN, остаётся заблокированным. Чтобы осознанно вернуться к прямому интернету, выберите «Выключить».

Закрытие окна пульта не выключает AutoTurn. Открыть пульт и изменить режим можно из значка в верхнем меню.

## Маршрутизация

![Маршруты](assets/routes.png)

- **Весь интернет:** трафик направляется через VPN.
- **Выбранные направления:** сервисы из каталога, собственные домены и IP-подсети направляются через VPN; остальной трафик идёт напрямую.

Откройте страницу маршрутов, выберите режим, найдите нужные сервисы и отметьте их. Добавьте собственные домены или IP/CIDR при необходимости. При подключённом VPN проверьте один выбранный и один обычный сайт. Изменение правил влияет на маршруты; существующие соединения в браузере могут потребовать переподключения или перезапуска страницы.

Каталог GeoAggregator обновляется отдельно. Обновление базы сохраняет пользовательские правила. Через импорт доступны IP-списки из файла, HTTPS-источника и списки HydraRoute. Экспорт/импорт JSON переносит настройки маршрутизации; VPN-профиль следует импортировать отдельно.

Шифрованный DNS в браузере, неизвестные домены и общие IP нескольких сервисов могут влиять на распознавание направлений. При сомнении используйте полный туннель и проверяйте фактический внешний IP нужного соединения. Физические IPv6-only сети и IPv6 Endpoint пока не поддерживаются.

## Настройки

![Настройки](assets/settings.png)

Пульт, верхнее меню и страница маршрутов имеют независимые оформления. Можно настроить автозапуск и список домашних сетей. Если имя Wi-Fi недоступно, проверьте разрешения геолокации AutoTurn в системных настройках.

## Обновления

Фоновая проверка проходит раз в час при работающем приложении; ручная кнопка «Проверить обновления» доступна независимо от расписания. При новой версии появляется уведомление и индикатор в пульте/меню. Установка начинается по вашему действию, с подтверждением прав администратора.

**С 0.1.9 на 1.0.0:** проверьте обновления, установите новую версию и убедитесь, что видите 1.0.0. Профили, домашние сети и настройки сохраняются. При повторном запросе macOS разрешите AutoTurn доступ к Связке ключей. [Полные изменения относительно 0.1.9](../releases/1.0.0/notes.md).

**Обновление до 1.0.3 без инструментов разработчика.** Если старая версия сообщает «Пакет не прошёл проверку подписи или совместимости Intel/Apple Silicon», скачайте [ZIP 1.0.3](https://github.com/cveloy102/autoturn-macos/releases/download/macos-v1.0.3/AutoTurn-1.0.3-macOS.zip) вручную. Выберите «Завершить…» в старом приложении, распакуйте ZIP и замените AutoTurn.app в «Программах». Откройте новую версию и установите VPN-службу из пульта с подтверждением прав администратора. Профили и настройки не удаляйте: они сохраняются отдельно. Ошибочная проверка находится в старом обновляторе, поэтому повторная автоматическая установка может не помочь. Xcode и Command Line Tools для 1.0.3 не нужны.

## Если что-то пошло не так

**Нет интернета после сбоя.** Откройте пульт, используйте восстановление интернета и проверьте результат. Для прямого доступа выберите «Выключить». Ошибка восстановления требует внимания: не считайте сеть восстановленной только по нажатию кнопки.

**AutoTurn не открывается, а интернет заблокирован.** В версии 1.0.2 аварийное восстановление можно запустить независимо от окна приложения. Откройте Терминал и выполните:

```sh
sudo "/Library/Application Support/AutoTurn/AutoTurnHelper" --emergency-recover
```

Введите пароль администратора (символы не отображаются). Сообщение `AutoTurn network settings removed; normal network restored` подтверждает успешную очистку настроек AutoTurn. При ошибке сохраните её текст. Команда не требует доступа к интернету; она требует установленного исправного AutoTurnHelper.

**Закрытие и сон.** Красный крестик скрывает окно; VPN и автоматика продолжают работать. Для обычного выхода используйте «Завершить…»: приложение запрашивает отключение VPN перед выходом. При недоступной службе отключение не гарантируется. Принудительное завершение приложения не выключает фоновую службу; в «Авто» дома служба может потерять подтверждение домашней сети и включить VPN с блокировкой. После сна восстановление может занимать десятки секунд. Если домашняя сеть не подтверждена и VPN не подключается, прямой доступ остаётся закрытым; используйте восстановление для осознанного перехода на обычный интернет.

**VPN не подключается.** Проверьте доступность интернета в режиме «Выключить», корректность профиля и Endpoint, затем повторите подключение. Неподдерживаемые или некорректные параметры импорта показываются как ошибка.

**Дома включается VPN.** Проверьте текущее имя Wi-Fi, наличие этой сети в домашнем списке и разрешения геолокации. Подключение по Ethernet не предоставляет имя Wi-Fi.

**Не появляется обновление.** Убедитесь, что приложение имеет доступ к GitHub, и выполните ручную проверку. Ошибки фоновой проверки не создают уведомлений; следующая попытка происходит через час.

**Нужен отчёт об ошибке.** [Создайте issue](https://github.com/cveloy102/autoturn-macos/issues/new) с версией macOS, архитектурой, версией приложения, режимом и шагами. Не публикуйте ключи или полный `.conf`.

## Переход на 1.0.4

Из-за смены ключа проверки первый переход со старых релизов выполняется вручную: выберите «Завершить…», скачайте ZIP из релиза 1.0.4 и замените только AutoTurn.app в «Программах». Данные приложения и Keychain не удаляйте. После запуска мастер сам проверит разрешения и службу. Сохранённый «Выкл» остаётся выключенным.

Перед заменой экспортируйте правила через «Маршруты → Экспорт». Существующие правила будут перенесены в независимое хранилище `~/Library/Application Support/AutoTurn/routing-state/`. Профили остаются в Связке ключей. Последующие обновления после 1.0.4 можно устанавливать из приложения.
