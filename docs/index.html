[ GET STARTED ]

Первый запуск_

  1. Скачай и распакуй архив

    Перенеси AutoTurn.app в «Программы». Одна сборка подходит для Intel и Apple Silicon.

  2. Открой AutoTurn

    Если macOS остановит первый запуск, разреши именно AutoTurn в «Системные настройки → Конфиденциальность и безопасность» и снова открой приложение.

  3. Добавь профиль AmneziaWG .conf

    Кнопка «Добавить профиль» или перетаскивание файла в пульт. Импортированные ключи и настройки хранятся в Связке ключей macOS.

  4. Установи VPN-службу и задай домашний Wi-Fi

    Пульт запросит права администратора для установки службы. Разреши определение имени Wi-Fi, добавь домашнюю сеть и выбери «Авто».

Когда выйдет новая версия_

AutoTurn проверяет GitHub раз в 24 часа во время работы, а также после запуска или пробуждения, если проверка уже пора. Кнопка ручной проверки находится в пульте и верхнем меню.

По уведомлению открывается предложение обновления. После загрузки проверяются подпись и контрольная сумма. Установка запрашивает права администратора, перезапускает приложение и сохраняет профили. macOS может повторно запросить доступ к Связке ключей.

Нативно для Mac_

AppKit, AmneziaWG 3.1, нативные x86_64 и arm64 компоненты. Пульт можно закрыть: приложение продолжит работать в строке меню.

В GitHub Actions проверяются сборка, запуск интерфейса, движка и службы на Intel и Apple Silicon. Поведение реального VPN также проверяется на физическом Mac. Для этой сборки используется локальная ad hoc подпись.
