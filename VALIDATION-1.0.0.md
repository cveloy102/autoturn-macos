# Проверка опубликованного AutoTurn 1.0.0

Версия **1.0.0**, сборка **100**. Исходный коммит кандидата: `1be0d5ff1f852cd30dcc816c97b7d9c6c679f6be`.

- [Сборка и тесты](https://github.com/cveloy102/autoturn-macos/actions/runs/38220065049): успешно на macOS 14/15 Apple Silicon и macOS 15 Intel. Общие/сервисные/аудитные тесты, тесты патчей routing-core, universal build, проверка встроенной конфигурации и нативный smoke.
- [Проверка точного подписанного архива и публикация](https://github.com/cveloy102/autoturn-macos/actions/runs/38221870998): успешно на всех трёх раннерах. Проверены Ed25519 метаданных и ZIP, SHA-256, версия/сборка, исходный коммит и CI run, подпись bundle, четыре универсальных компонента, нативное выполнение и IPC.
- Обновлятор из публичного **0.1.9** скомпилирован отдельно: принимает подписанные метаданные и ZIP 1.0.0 для установленных сборок 9 и 18, отвергает повреждённый ZIP, не предлагает обновлять сборку 100 на неё же. Та же проверка выполнена текущим кодом.
- Установленное приложение 0.2.0-dev build 18 проверило публичный GitHub feed, нашло 1.0.0 build 100, скачало опубликованный ZIP и подтвердило SHA-256 и Ed25519. Установка не запускалась; пользователь проверяет её сам.
- GitHub Pages просмотрен в браузере; реальные скриншоты загружаются. При ширине 390 px отсутствует горизонтальное переполнение. Ссылки разделов и раскрытие FAQ работают.

[Публичный релиз](https://github.com/cveloy102/autoturn-macos/releases/tag/macos-v1.0.0). ZIP: 37 050 652 байта. SHA-256: `af3a0f811acfbdffb29f305f3ec138e84e582d714f78cd559372f43b15bad0f5`.

Релиз включает подписанные метаданные, контрольные суммы, исходники AutoTurn и полные соответствующие модифицированные исходники AWG/routing-core. Закрытый ключ подписи не передавался в GitHub или CI.

Реальные сетевые сценарии Intel описаны в [аудите](AUDIT-2026-10-12.md). Работа пользовательского VPN на физическом Apple Silicon, сон/пробуждение, captive portal и пользовательская установка OTA не считаются проверенными этим отчётом.
