# AutoTurn 1.0.7

- Исправлено добавление X/Twitter и других сервисов после сокращения внешнего каталога. YouTube, OpenAI, GitHub Copilot и уже сохранённые сервисы остаются доступны; недоступный старый список не блокирует добавление других сервисов.
- Для Google, Claude, GitHub и Discord включены резервные доменные списки из закреплённой версии v2fly/domain-list-community. Они доступны и без старого кэша. Когда источник отдаёт только IP-подсети, существующие домены сохраняются; старые IP заменяются свежими.
- Ранее сохранённые сервисы без базовых доменов автоматически восстанавливают доменную часть из встроенной базы. Свои домены, IP-подсети, назначения и VPN-профили сохраняются.
- Общий лимит маршрутов увеличен с 12 000 до 30 000 записей: Google и GitHub можно использовать вместе. Ограничение размера настроек сохраняется.
- В карточке показаны отдельно домены и IP-подсети. Ошибка загрузки при добавлении сервиса показывается отдельным окном.

Нужно обновить VPN-службу: приложение запросит пароль администратора macOS. Сбрасывать маршруты не требуется. Версия 1.0.6 была промежуточной тестовой сборкой; обновляться нужно до 1.0.7.
