AutoTurn 1.0.5 — защита DNS

• В настройках можно выбрать основной DNS и до двух резервных: Cloudflare, Quad9, Google, DNS VPN-профиля или свой HTTPS DNS.
• При работающем VPN DNS AutoTurn идёт через туннель. Адрес самого VPN-сервера определяется через зашифрованный DNS без обращения к DNS роутера.
• В режиме «По правилам» при отказе VPN обычные сайты используют зашифрованный прямой резерв; DNS доменов из VPN-правил ждёт защищённого подключения. В полном режиме прямого резерва нет.
• Ответы DNS кэшируются с учётом TTL и очищаются при смене профиля, сети или правил. Это сокращает повторные запросы при открытии страниц.
• Дома в режиме «Авто» и после выключения сохраняется обычная работа через роутер. Профили и правила сохраняются.

После обновления потребуется обновить VPN-службу с системным подтверждением macOS.

Границы защиты: встроенный DoH браузера и скрытые имена соединений могут обходить распознавание доменных правил в выборочном режиме. IP-списки без доменов не позволяют заранее задержать DNS имени. Для наиболее строгого покрытия используйте «Всё через VPN». Прямой DNS-резерв раскрывает исходный IP выбранному DNS-провайдеру. Защита DNS не гарантирует отсутствие блокировок аккаунтов.
