AutoTurn 1.0.3

Исправлена установка и проверка обновлений на Mac без Xcode и Command Line Tools.

- Обновлятор и установщик больше не вызывают lipo, зависящий от инструментов разработчика Apple. Для проверки используется системный codesign.
- Проверка подписи сохранена для всех архитектур каждого компонента. Обновлятор по-прежнему требует полный пакет для Intel и Apple Silicon.
- Сообщения теперь различают ошибку подписи и отсутствие нужной архитектуры и указывают проблемный компонент.
- Добавлены проверки исправного пакета при недоступных инструментах разработчика и отклонения подписанного пакета без ARM-компонента.

Если старая версия показывает «Пакет не прошёл проверку подписи или совместимости Intel/Apple Silicon», она может не суметь обновиться автоматически: ошибочная проверка находится в уже установленном приложении. В этом случае один раз установите 1.0.3 вручную:

1. Скачайте AutoTurn-1.0.3-macOS.zip из этого релиза и распакуйте его.
2. В работающем AutoTurn выберите «Завершить…» и подтвердите отключение VPN. Красный крестик только скрывает окно.
3. Перенесите новый AutoTurn.app в «Программы» (/Applications) с заменой старого приложения.
4. Откройте новый AutoTurn, установите VPN-службу из пульта и подтвердите права администратора. При запросе macOS разрешите доступ к сохранённым настройкам в Связке ключей.

Профили, домашние сети и правила не удаляются и не сбрасываются. Установка Xcode/Command Line Tools для работы AutoTurn не требуется. При блокировке запуска macOS разрешите запуск конкретного приложения через системные настройки конфиденциальности и безопасности.

Этот выпуск не меняет политику блокировки трафика и восстановления VPN версии 1.0.2. Описанные в 1.0.2 ограничения после сна и принудительного завершения сохраняются.
