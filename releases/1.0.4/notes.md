# AutoTurn 1.0.4

**Важно: переход с 1.0.3 и более ранних версий — вручную.** В 1.0.4 обновлён ключ проверки обновлений, поэтому старый встроенный обновлятор этот выпуск не примет. Скачайте ZIP и замените только приложение в «Программах», сохранив данные. После ручного перехода следующие обновления будут доступны из приложения.

Исправления и новые возможности относительно последнего публичного релиза **1.0.3**. Универсальная сборка **110** для Intel и Apple Silicon, macOS 13 и новее.

## Подключение VPN и DNS

- Исправлено подключение после импорта профиля при работающем режиме «По правилам»: приложение могло сохранить служебный fake-IP вместо настоящего адреса VPN-сервера. Теперь имя сервера разрешается службой через DNS физической сети; старый ошибочный адрес исправляется при подключении.
- Для прямых направлений используется DNS текущей физической сети. Приложение больше не предполагает, что DNS всегда расположен на адресе шлюза.
- Ошибка определения DNS-адреса выбранного VPN-сервера запускает переход к резервному профилю вместо зависания на том же сервере.
- Два проверочных HTTPS-сайта проверяются параллельно: достаточно первого успешного ответа. Повторное применение неизменённых настроек не перезапускает текущую проверку. Ручная проверка больше не выдаёт прежний успех до завершения нового запроса.
- При быстрых повторных подключениях настоящий адрес сервера временно используется повторно в пределах той же сети. При смене сети/DNS, переходе домой или выключении кэш очищается.

## Профили

- Можно назначить основной VPN-профиль. Новый цикл подключения начинается с него, затем используются резервные по порядку. Работающий резерв сохраняется до нового цикла.
- Ручная смена профиля и кнопка «Следующий профиль» требуют подтверждения. Во время подключения повторный выбор показывает сообщение об ожидании и не запускает цепочку лишних переподключений. Поздние ответы не меняют более свежий выбор.
- Исправлен drag & drop файлов .conf, когда приложение занято. Принятые файлы ожидают в очереди и импортируются после завершения текущей операции. В профилях и мастере настройки есть отдельная область перетаскивания.

## Разрешения и VPN-служба

- Мастер сам проверяет необходимые доступы, пропускает готовые шаги и запрашивает недостающие разрешения. Если всё готово, при обычном запуске лишнее окно не появляется.
- Если служба отсутствует или не подходит новой сборке, приложение самостоятельно начинает её установку/обновление. Остаётся подтвердить системный запрос администратора macOS. До и после установки проверяется реальный ответ службы, чтобы не показывать ложную ошибку при успешном запуске.
- Проверка геолокации для определения домашнего Wi-Fi выполняется независимо от выбранного режима и не ждёт медленного чтения имени сети. При отказе доступны инструкции и переход к системным настройкам. Уведомления необязательны для VPN.
- Сохранённый «Выкл» не мешает настройке службы и разрешений и остаётся выключенным после неё. Установка службы сама по себе не включает VPN.
- Ручная кнопка проверки показывает окно результата «Все необходимые разрешения есть», которое остаётся открытым до «Готово» или закрытия окна. Фоновые проверки больше не закрывают его сразу.
- Отмена системного запроса или «Позже» не вызывает повторяющиеся запросы на каждом тике таймера. Доступен ручной повтор.

## Сохранение маршрутов

- При первом запуске существующие правила переносятся в независимое хранилище в папке пользователя вне приложения. Замена .app и пустая запись от старой версии не стирают эту копию.
- Сохраняется предыдущая копия правил. При повреждении текущего файла используется предыдущий; если обе копии повреждены, приложение не записывает поверх них пустой список.
- Сохранение VPN-профиля, режима или других настроек не может изменять правила. Конфликтующие изменения самих правил обнаруживаются. Намеренное удаление списка сохраняется и не отменяется автоматическим восстановлением.
- Обновление базы маршрутов начинается после загрузки сохранённых настроек. Версия приложения и номер сборки видны внизу основного окна и в настройках.

## Обновление с 1.0.3

Скачайте `AutoTurn-1.0.4-macOS.zip` из этого релиза. В старой версии выберите «Завершить…», распакуйте ZIP, замените `AutoTurn.app` в `/Applications` и откройте его. Не удаляйте данные приложения и запись настроек в Связке ключей. Профили и домашние сети сохраняются; существующий список маршрутов переносится автоматически. Выбранный «Выкл» также сохраняется. Для обновления службы подтвердите запрос администратора; macOS может повторно запросить доступ к Связке ключей и геолокации для новой подписи приложения.

Перед обновлением рекомендуем экспортировать текущие правила через «Маршруты → Экспорт». Уже утраченный до создания копий список новая версия восстановить не сможет. Ранее выпущенные 0.1.x/1.0.0–1.0.2 с ошибкой проверки пакета при отсутствии инструментов разработчика могут потребовать ручной установки ZIP.

После обновления правила хранятся в `~/Library/Application Support/AutoTurn/routing-state/current.json`, предыдущая копия — `previous.json`. Это экспорт только маршрутов, без VPN-ключей. Профили остаются в Связке ключей.

Проверка настоящего VPN-трафика и блокировка выбранных VPN-направлений при отказе сохранены. Улучшения не гарантируют мгновенное подключение: недоступность сети, DNS или сервера по-прежнему требует повторных попыток. Ограничения восстановления после сна и принудительного завершения из 1.0.2 полностью не устранены. Приложение имеет ad hoc подпись, без Developer ID и нотариализации; подлинность дальнейших встроенных обновлений проверяется Ed25519-ключом, включённым в 1.0.4.
