# Проверка AutoTurn 0.1.4 — 11 октября 2026

Установлена `/Applications/AutoTurn.app`. Обновлены подписи и привязка root-службы. Приложение x86_64 + arm64, полный codesign verify прошёл. Код службы/движка совпадает с проверенной 0.1.3; изменены AppKit-меню и частота наблюдения.

## Реальная сеть

На внешней сети до обновления: физический шлюз 192.168.31.1, оба split routes VPN через utun4, DNS 1.1.1.1, HTTPS 200. Возврат командой networksetup на Keen_5G: домашний шлюз, исчезновение обоих VPN-маршрутов, DNS роутера и HTTPS 200. При переподключении были краткие неуспешные HTTPS-запросы; непрерывность соединения во время смены Wi-Fi не заявляется. Запись: work/network-debug/return-home-0.1.3.log.

На установленной 0.1.4 пройден нормальный путь приложения/службы: Вкл. → Авто дома → Вкл. → Выкл. → Авто дома. На каждом шаге успешны curl и системный URLSession HTTPS; Авто дома выдержано по 12 секунд. После завершения нет VPN split routes, приложение открыто в Авто дома. Запись: work/network-debug/live-0.1.4.log. Пользовательский профиль и ключи не печатались и не включены в сборку.

## Шторка

Автоматическая проверка настоящего NSPopover: открытие; изменение статуса обновляет содержимое, пока меню остаётся открытым; неизменившийся статус сохраняет текущий NSView; внутренний клик не закрывает; внешний клик в другое окно приложения закрывает; наблюдатели удаляются. Также проверены четыре вкладки, пустой/три профиля, ширины пульта 700/760/1000, меню 292, импорт, профильные строки и файловый pasteboard. Тест не использует Keychain или сеть. Запись: work/network-debug/live-menu-ui.log.

Для клика в другом приложении дополнительно установлен стандартный глобальный монитор мыши, для потери активности — наблюдатель didResignActive. Физический пользовательский клик в другом приложении не воспроизводился автоматизацией; проверен обработчик внешнего клика. Наблюдатели существуют только при открытой шторке.

Опрос состояния каждую секунду при открытом меню; в фоне — пять секунд. Сетевые события немедленно передаются службе, SSID проверяется раз в три секунды. Таймеры в common modes. Изменение видимых данных определяется отдельно от прочих событий, чтобы меню не перестраивалось без необходимости.

Ранее прошли 71 общая проверка и 13 переходов службы. Для 0.1.4 служба/движок не изменялись, эти проверки не повторялись. Остаются реальный M1 и отказ резервных серверов.
